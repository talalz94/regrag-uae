# Model card: RegRAG UAE retrievers (slice 1)

## What it is

Retrieval systems that rank ADGM regulatory passages for a compliance question and return each passage with its citation (document number and rule reference). Nothing is trained or fine tuned in this slice; the systems use off the shelf components with fixed settings.

| System | Components | License |
|---|---|---|
| BM25 | `bm25s` 0.3.16, Lucene scoring, k1 = 1.5, b = 0.75, 33 English stopwords, Snowball stemmer (`PyStemmer`), rule numbers such as 11.2.1 kept as one token | MIT; PyStemmer MIT and BSD |
| Dense | [BAAI/bge-small-en-v1.5](https://huggingface.co/BAAI/bge-small-en-v1.5) at revision `5c38ec7c405e`: 33M parameters, 384 dimensions, 512 token limit, BGE query instruction on questions, exact cosine search | MIT |
| Hybrid | Reciprocal rank fusion (k = 60) over the top 100 from BM25 and dense | |
| Ablations | BM25 without stemming; [BAAI/bge-base-en-v1.5](https://huggingface.co/BAAI/bge-base-en-v1.5) at revision `a5beb1e3e68b` (110M parameters) alone and fused with BM25 | MIT |

Model weights are downloaded from Hugging Face at the pinned revisions on first use and are never committed.

## Intended use

- Research and demos: finding the ADGM passages that bear on a question, with citations a person can check.
- The retrieval stage of a cited answer system, where a person reads the cited rules before acting.

## Out of scope

- Legal or compliance advice, or any decision made without a qualified person reading the source rules.
- Current law. The corpus is a snapshot from around 2024.
- Other regulators and jurisdictions, and questions in Arabic. None of these is tested.

## Evaluation

Official ObliQA dev and test splits, binary relevance, metrics as defined in trec_eval. The main metric is Recall@10, as in the RIRAG shared task. Results, latency and the command behind every number are in the [README](../README.md#results); raw results with hardware and package versions are in `results/`.

## Limitations and risks

- The questions were generated by GPT-4 from the gold passages, so they share wording with them. This favours lexical matching and likely overstates quality on real questions.
- Only the passages a question was generated from count as relevant, so some correct results are scored as misses.
- The dense model truncates long passages at 512 tokens, which mostly affects long tables.
- In compliance work, a missed passage can hide an obligation. The answer slice will refuse to answer when retrieval looks weak, rather than answer from partial evidence.
